# 004. Постоянное переподключение к WiFi

**Статус:** причина не установлена.

## Симптомы

Лампа постоянно переподключается к WiFi и через какое-то время зависает. Наблюдалось только на одной лампе; на другой с аналогичной конфигурацией всё работало нормально.

## Возможные причины

- ESP8266 вышел из строя.
- Проблема антенны или пайки.
- Нестабильное питание.
- Деградация RF-тракта.

Подтверждённая причина и проверенное решение для этого случая не зафиксированы. Само совпадение конфигурации двух ламп не исключает различий в железе и питании.
