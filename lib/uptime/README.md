# GyverLamp Uptime

This is a local fork of [Uptime Library](https://github.com/YiannisBourkelis/Uptime-Library), sourced from upstream v1.0.0.

The API renames are:

- `uptime` → `Uptime`; `uptime_formatter` → `UptimeFormatter`
- `getMilliseconds()`, `getSeconds()`, `getMinutes()`, `getHours()`, and `getDays()` → `milliseconds()`, `seconds()`, `minutes()`, `hours()`, and `days()`
- `getUptime()` and `getUptimeWithMillis()` → `uptime()` and `uptimeWithMillis()`
